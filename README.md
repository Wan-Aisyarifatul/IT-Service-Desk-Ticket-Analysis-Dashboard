# IT Service Desk Analytics Dashboard

Personal project — Power BI dashboard analyzing IT service desk ticket performance across teams and agents.

## Overview
An end-to-end Power BI dashboard built to track and analyze IT service desk operations: SLA compliance, ticket volume, team/agent performance, and customer satisfaction — across 16,000+ tickets.

## Dashboard Pages
1. **Executive Summary** — high-level KPIs (total tickets, open tickets, First Response SLA %, satisfaction %) with trend indicators.
2. **SLA Dashboard** — First Response vs Resolution SLA compliance, average response time by priority, failed-SLA ticket tracking.
3. **Team Dashboard** — team-level SLA comparison, workload distribution, ticket volume by category.
4. **Agent & Individual** — agent-level performance rankings, satisfaction scores, workload distribution.
5. **Ticket Analysis** — SLA performance by category, ticket volume by source channel, priority-level impact on satisfaction.

## Key Metrics Tracked
- First Response SLA % / Resolution SLA % (target: 90%)
- Customer satisfaction score (target: 90%)
- Average response time by priority (High/Medium/Low)
- Ticket volume by category (Network, Hardware, Software, Others) and source channel (Email, Phone, On-site)

## Tools Used
- **Power BI** — DAX measures, Power Query, interactive slicers (Year, Month, Team, Priority, Category, Source)
